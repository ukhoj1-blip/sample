# 법인카드 집근처 분석

법인카드 사용내역의 가맹점 주소와 사용자 집주소 사이 거리를 카카오지도로 계산해, 사적 사용이 의심되는 거래를 찾아냅니다.

## 웹에 배포하기

이 앱은 서버 코드가 없는 **정적 웹사이트**입니다. 이 폴더를 그대로 올리면 어디서든 동작합니다. 카카오지도와 국세청 API는 모두 브라우저에서 직접 호출합니다.

카드내역, 집주소, 조회 결과는 **각 사용자 브라우저에만** 저장됩니다. 사이트 주소를 아는 사람이 열어도 다른 사람의 데이터는 보이지 않습니다.

### 방법 A. Netlify Drop (가장 쉬움, 무료)

1. https://app.netlify.com/drop 에 접속해 가입하거나 로그인합니다.
2. `card-home-analyzer` 폴더를 통째로 끌어다 놓습니다. 몇 초 뒤 `https://xxxx.netlify.app` 주소가 생깁니다. Site settings에서 주소 이름을 바꿀 수 있습니다.
3. 카카오 디벨로퍼스 **[앱] > [플랫폼 키] > [JavaScript 키] > JavaScript SDK 도메인**에 그 주소를 추가합니다. 예: `https://xxxx.netlify.app`
4. 수정본을 올릴 때는 Netlify 사이트의 Deploys 탭에 폴더를 다시 끌어다 놓습니다.

### 방법 B. GitHub Pages (무료)

1. GitHub 저장소를 만들고 이 폴더의 파일을 올립니다.
2. Settings > Pages > Branch를 `main` / `/(root)`로 지정합니다.
3. 생성된 `https://<계정>.github.io/<저장소>` 주소의 **도메인 부분**을 카카오 JavaScript SDK 도메인에 등록합니다. 예: `https://<계정>.github.io`

### 방법 C. 사내 웹서버 (IIS, Nginx 등)

폴더를 웹 루트에 복사하고, 사내 주소(예: `http://card.회사.local`)를 카카오 도메인에 등록합니다. 사내 전용이면 외부 노출 걱정이 없습니다.

### 공통 키 넣어두기 (선택)

`js/config.js`의 `kakaoKey`에 카카오 JavaScript 키를 넣고 배포하면, 사용자마다 키를 입력할 필요가 없습니다. 카카오 키는 등록 도메인에서만 동작하므로 공개되어도 괜찮습니다. 공공데이터포털 키(`ntsKey`)는 공개 사이트라면 넣지 말고 각자 입력하게 하세요.

## 내 PC에서만 실행

`start.bat`을 더블클릭하면 http://localhost:8080 이 열립니다. Python이나 Node는 없어도 됩니다. 카카오지도는 `file://`로 열면 동작하지 않으므로 이 방법이나 배포 주소로 여세요.

## 카카오 키 준비 (최초 1회)

1. https://developers.kakao.com 에서 애플리케이션을 만듭니다.
2. 왼쪽 메뉴 **[앱] > [플랫폼 키] > [JavaScript 키]**를 클릭하고, **JavaScript SDK 도메인**에 `http://localhost:8080`을 등록한 뒤 저장합니다. 사내 서버에 올릴 경우 그 주소도 등록합니다.
3. 왼쪽 메뉴 **[카카오맵] > [사용 설정]**에서 상태를 **ON**으로 바꿉니다.
4. 같은 JavaScript 키 화면에서 키 값을 복사해 앱의 ⚙ 설정 탭에 입력합니다. REST API 키가 아니라 **JavaScript 키**여야 합니다.

## 사용 순서

1. **데이터 업로드**: 카드사 엑셀/CSV를 올립니다. 헤더는 순번, 카드번호, 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소 등입니다. 여러 파일을 올리면 중복은 자동으로 제거됩니다.
2. **집주소 관리**: 이용자별 집주소를 입력합니다. `양식 다운로드`로 받은 엑셀(이용자명, 집주소)을 채워 일괄 업로드할 수도 있습니다.
3. **분석 실행**: 주소를 좌표로 변환하고 거리를 계산합니다. 변환 결과는 캐시되므로 다음부터는 새 주소만 조회합니다.
4. **대시보드 / 지도 / 상세 내역**에서 결과를 확인하고, 필요하면 엑셀로 내보냅니다. 엑셀에는 분석결과와 사용자별요약 두 시트가 들어갑니다.

## 휴일 사용 분석 (⑤ 휴일 사용 탭)

카드내역만 올리면 카카오 연결 없이 바로 볼 수 있습니다. 화면 구성은 다음과 같습니다.

- 휴일 사용 건수·금액·비중, 휴일+집근처, 휴일+심야, 휴일+고위험업종 집계
- 사용자별, 업종별, 날짜별, 월별 현황. 날짜를 누르면 아래 목록이 그 날짜로 좁혀집니다.
- 의심 거래만 보기: 휴일 거래 중 집근처, 주의 반경, 심야, 고위험업종에 해당하는 것만 표시
- 엑셀 다운로드

**휴일 기준**은 공휴일(2024~2026 내장)과 일요일이 기본입니다. 설정에서 다음을 조정할 수 있습니다.

- 토요일 포함 여부 (기본 포함)
- 근로자의날(5/1) 포함 여부 (기본 포함)
- 추가 휴일: 창립기념일 등
- 휴일 제외일: 주말 특근일 등

## 휴폐업 조회 (⑥ 휴폐업 조회 탭)

카드내역의 사업자 등록번호로 국세청 사업자 상태(계속, 휴업, 폐업)를 조회합니다.

**준비 (최초 1회)**

1. [data.go.kr](https://www.data.go.kr/data/15081808/openapi.do)에서 **국세청_사업자등록정보 진위확인 및 상태조회 서비스**를 활용신청합니다. 자동승인입니다.
2. 마이페이지 > 데이터활용 > Open API > 개발계정에서 **일반 인증키(Decoding)**를 복사해 ⚙ 설정 탭에 입력합니다. 새로 발급한 키는 반영까지 1시간가량 걸릴 수 있습니다.

국세청 API는 브라우저에서 직접 호출합니다. 사내 방화벽 등으로 직접 호출이 막히면 `start.bat` 서버의 `/api/nts-status` 중계로 자동 재시도합니다.

**판정**

| 판정 | 조건 | 위험점수 |
|---|---|---|
| 폐업 후 거래 | 국세청 폐업일보다 이용일이 늦음 | +40 |
| 미등록 사업자 | 국세청에 없는 사업자번호 | +20 |
| 현재 휴업 | 조회 시점 휴업 중. 휴업 시작일은 제공되지 않습니다. | – |
| 거래 후 폐업 | 거래 이후 폐업 (참고용) | – |
| 과세유형 불일치 | 카드 전표와 국세청 과세유형이 다름 (참고용) | – |

이 판정들은 위치와 관계없이 적용됩니다. 조회 결과는 브라우저에 캐시되며, `전체 다시 조회`로 최신화할 수 있습니다.

## AI 요약·경영진 보고서 (⑧ 탭, Gemini)

**준비 (최초 1회)**

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 발급합니다.
2. ⚙ 설정의 **제미나이(Gemini) AI 연결**에 붙여넣고 **저장 후 연결 테스트**를 누릅니다. 사용 가능한 모델 목록이 자동으로 채워지며, 기본은 flash 계열입니다.

**기능**

- **이상징후 요약**: 한 줄 요약, 핵심 이상징후, 우선 소명 확인 대상 표, 권장 조치
- **경영진 보고서**: 보고 요약부터 향후 조치 계획까지 7개 장. 보고자, 수신, 분량, 어조, 추가 지시사항을 지정할 수 있습니다.
- 작성 과정이 실시간으로 표시되며, 중간에 **중지**할 수 있습니다.
- 결과는 **복사**(서식 포함, 메일·한글·워드에 붙여넣기), **인쇄·PDF**, **Word 다운로드**로 내보낼 수 있습니다. 마지막 결과는 브라우저에 저장됩니다.

**개인정보 보호**

- AI에는 집계 수치와 위험점수 상위 30건만 보냅니다. 집주소, 카드번호, 가맹점 주소는 보내지 않습니다.
- 기본값으로 이용자 이름을 `직원01` 같은 가명으로 바꿔 보내고, 결과를 받은 뒤 화면에서 실명으로 되돌립니다.
- 보고서 양식에 입력한 보고자·수신은 그대로 보내집니다.
- **AI에 보낼 데이터 보기**로 전송 내용을 미리 확인할 수 있습니다.
- AI는 받은 수치만 쓰도록 지시되어 있지만 초안이므로 결재 전에 수치를 확인하세요.

## 판정 기준 (설정에서 변경 가능)

| 판정 | 조건 |
|---|---|
| 집근처 | 집에서 500m 이내 |
| 주의 | 집에서 1.5km 이내 |
| 회사근처 | 회사 반경 안에 있고, 집보다 회사에 더 가까움 (회사 주소를 넣은 경우만) |
| 분석제외 | 취소 전표, 해외 거래, 제외 업종(PG·온라인·택시 등은 카드사 주소가 실제 매장 위치가 아님) |
| 위치불명 | 주소 검색 실패 |

**위험점수**: 집근처 +50, 주의 +20. 집근처나 주의 거래가 주말·공휴일이면 +20, 심야(22~06시)면 +15, 고위험 업종(주유·편의점·마트 등)이면 +15를 더합니다. 같은 집근처 가맹점을 3회 이상 쓰면 +10입니다.

## 주소 처리

카드사 주소에는 건물명·층·호수가 붙거나 `서초동 1670 15`처럼 하이픈이 빠진 경우가 많습니다. 앱은 다음 순서로 후보를 시도합니다.

1. 도로명+건물번호 또는 지번
2. 원문
3. 뒤 단어를 하나씩 줄인 주소

그래도 찾지 못하면 `지역 + 가맹점명`으로 장소 검색을 합니다. 동 단위로만 찾은 좌표는 `동단위` 플래그를 붙여 오차가 있을 수 있음을 표시합니다.

## 데이터 보관

- 카드내역, 집주소, 좌표 캐시, 설정은 이 브라우저의 localStorage에만 저장됩니다. 서버로 업로드되지 않습니다.
- 좌표 변환 시에는 **주소 문자열만** 카카오 로컬 API로 전송됩니다. 가맹점 주소와 집주소가 해당됩니다.
- 공휴일은 2024~2026년이 내장되어 있습니다. 창립기념일 등은 설정의 `추가 휴일`에 입력하세요.
